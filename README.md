GTCEuM More Things

GTCEuM More Things is an expansion addon for GregTech CEu Modern, designed to introduce additional machines, multiblocks, materials, processing systems, and other technological features.

About

This project aims to expand the GregTech CEu Modern experience by introducing new industrial content while maintaining compatibility with its existing progression and mechanics.

GTCEuM More Things is an independent addon and is not an official project of the GregTech CEu Modern team.

Features

- Integration with GregTech CEu Modern.

Features are subject to change during development.

Requirements

- Minecraft 1.20.1
- Minecraft Forge
- GregTech CEu Modern
